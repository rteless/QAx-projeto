# QAx-projeto

Projeto criado com o objetivo de aprofundar meus conhecimentos em automação de testes utilizando **Playwright**, **Cucumber**, **BDD/Gherkin** e **JavaScript**.

Este repositório será utilizado como ambiente de estudos e prática contínua, onde irei desenvolver cenários automatizados, organizar a estrutura de testes e aplicar boas práticas de automação.

Ao longo da evolução do projeto, serão trabalhados conceitos como:

- Testes funcionais automatizados
- BDD com Gherkin
- Cucumber
- Playwright
- JavaScript
- Page Object Model
- Boas práticas de locators
- Cenários positivos e negativos
- Testes regressivos
- Análise de falhas, logs e traces
- SonarQube para qualidade de código
- CI/CD com GitHub Actions

## Objetivo

Evoluir meus conhecimentos práticos em QA Automation, construindo uma estrutura de testes próxima de um cenário real de projeto.

Este repositório também será utilizado para registrar minha evolução técnica e novos aprendizados na área de qualidade de software.
